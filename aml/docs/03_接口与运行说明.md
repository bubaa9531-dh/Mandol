## 2. 契约（与 <https://agentmemoryleaderboard.ai/api-guide> 一致）

### Add 请求

```json
{
  "request_id": "eval:<run_id>:<benchmark>:<conv>:<chunk>",
  "messages": [
    {"role": "user", "timestamp": 1704067200000, "content": "raw memory text"}
  ],
  "user_id": "eval:<run_id>:<benchmark>:<conv>",
  "session_id": "eval:<run_id>:<sample>"
}
```

### Add 响应（HTTP 200，数据已持久化且立即可检索）

```json
{"success": true, "request_id": "...", "user_id": "...", "session_id": "..."}
```

### Search 请求

```json
{
  "query": "Which answer best matches the memory?",
  "options": ["A. ...", "B. ..."],
  "user_id": "eval:<run_id>:<benchmark>:<conv>",
  "top_k": 100
}
```

### Search 响应（data 为按相关度降序数组，数量 ≤ top_k；无结果返回空数组）

```json
{
  "data": [
    {"id": "mem_1", "content": "remembered fact text", "score": 0.87, "created_at": "2026-07-01T12:00:00Z"}
  ]
}
```

实现要点（均已内建）：

- Add 只有写入完成、可被 Search 检索到后才返回 200（不做 202/轮询）。
- `success` 恒为 `true`；`request_id/user_id/session_id` 逐字回显。
- `user_id` 是唯一检索隔离边界；`session_id` 不参与过滤；绝不跨用户检索。
- 检索返回正文为平台 Answer 阶段使用的记忆文本；Search 本身不生成最终答案。
- 错误采用标准 HTTP 状态码，业务错误体为 `{"detail":{"reason":"..."}}`；
  平台对 408/425/429/5xx 做有界重试，对 400/401/403/404 不重试。

## 3. 鉴权

- 由参赛方签发 **Memory System Key**（`AML_MEMORY_SYSTEM_KEY`，**不要**写入公开仓库）。
- 支持 `Authorization: Bearer <key>`、`Authorization: Token <key>`、
  `X-Api-Key: <key>` 三种方式。
- 未配置 Key 时接口开放（AML 仅允许 Smoke 阶段使用无鉴权端点），**正式评测前必须配置**。
- Eval/Leaderboard Key 与 Memory System Key 是两套凭证，勿混用、勿外泄。

## 4. 容量 / 超时 / 限流（报名时如实填写）

| 项 | 本实现默认 | 说明 |
| --- | --- | --- |
| Add 超时 | 60 s（`AML_ADD_TIMEOUT_SECONDS`） | 实际单批写入远快于此 |
| Search 超时 | 30 s（`AML_SEARCH_TIMEOUT_SECONDS`） | 稠密检索毫秒~百毫秒级 |
| 写入吞吐 | 单实例 ≥ 10 QPS（批量 Add 更高） | 视 embedding 硬件 |
| 检索吞吐 | 单实例 ≥ 10 QPS | Mandol 低延迟检索 |
| 限流 | 默认不限（`AML_RATE_LIMIT_RPM=0`） | 可设每分钟请求数；超限返回 429 + Retry-After |
| 数据留存 | 30 天自动清理 | `AML_DATA_TTL_DAYS=30`；也可按任务结束后手动清库 |
| 健康检查 | `/health` | 模型未就绪返回 503；就绪返回 200 |

## 5. 数据与隐私

- 日志不记录消息正文，只记录 request_id、user_id（或其摘要）、状态、耗时与数量级。
- 评测数据仅用于当次评测任务；不训练、不微调、不重建数据集、不对外传播；
  任务结束 30 天内删除（由留存线程与运维双保险执行）。
- 接口公网可达，URL 不含任何凭据；鉴权由 Memory System Key 保护。
