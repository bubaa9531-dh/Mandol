# 材料 04：合规与诚信声明（Compliance & Integrity Statement）

> 用途：正式提交 Full 前，需在平台 Evaluation 页面逐项确认检查清单（共 8 项，以页面为准）。
> 本文档用于内部核对与存档；提交前由负责人逐项勾选并签字，随申报材料备查。

## A. 材料与代码完整性

- [ ] 参赛身份、机构/团队、联系人、系统版本真实且可核验
- [ ] 公开 GitHub 仓库可访问：https://github.com/bubaa9531-dh/Mandol
- [ ] 参赛代码含固定 commit / tag（`v0.1.0-aml.1`，报名时锁定）
- [ ] README、Docker 启动命令、API 入口、依赖配置、运行步骤齐全
- [ ] 自研项目归属、论文/作者与**全部**赛事适配改动已披露（ATTRIBUTION.md / CHANGES.md）
- [ ] Add/Search 接口信息、鉴权、容量、超时、限流、留存说明已提交

## B. 接口契约与 Smoke

- [ ] Smoke 已通过：Add/Search、鉴权与端到端链路符合现行接入协议
- [ ] Add 同步返回：数据持久化且立即可检索后才返回 HTTP 200；`success=true`，ID 逐字回显
- [ ] Search 只返回记忆证据（`data` 数组、`id`/`content` 非空、数量 ≤ top_k、按相关度排序）；不生成最终答案、不把答案伪装成记忆记录
- [ ] 错误语义符合规范（400/422、401、403、404 不重试类；408/425/429/5xx 可重试类；业务错误体 `{"detail":{"reason":...}}`）

## C. 隔离与数据安全

- [ ] 记忆按 `user_id` 严格隔离；不跨用户/任务/样本/团队共享或检索
- [ ] `session_id` 仅作来源会话分组/元数据，不参与检索过滤
- [ ] 评测数据及其派生副本仅用于完成当次任务
- [ ] 不用于训练、微调、产品分析、数据集重建或对外传播
- [ ] 任务结束 30 天内删除评测数据（`AML_DATA_TTL_DAYS=30` 自动清理 + 运维兜底）
- [ ] 不记录含消息正文的日志；不把评测数据写入公开仓库

## D. 诚信承诺（严禁行为核查）

- [ ] 未硬编码任何答案或针对评测集的规则
- [ ] 未泄漏、未获取私有评测数据 / 金标准答案
- [ ] 未使用提示词注入、人工实时答题、结果操纵或恶意刷榜
- [ ] 未进行未披露的代码复用；未将评测数据用于训练/微调/数据集重建
- [ ] Search 未越界承担答题职责（答题、评分与编排由平台统一完成）

## E. 版本冻结与运行承诺

- [ ] 正式 Full 受理后：代码、镜像、API、鉴权与申报版本一致；不因结果不理想更换版本或撤回
- [ ] 接口在 2026-09-20 → 2026-11-04 公网稳定可访问，期间不改 API 契约、鉴权方式与容量设置
- [ ] URL 不含凭据，不指向回环/链路本地地址；Memory System Key 仅存于部署端环境变量

## F. 提交前复核

- [ ] 已在 Evaluation 页面确认全部 8 项 Full 检查项

- [ ] 已核对方法说明（材料 02）、接口运行说明（材料 03）与仓库代码一致
- [ ] 已更新材料中引用的锁定 commit / tag
