# 材料 04：合规与诚信声明（Compliance & Integrity）

> 提交 Full 前需在平台逐项勾选；本文件用于内部核对与存档。请负责人确认后签字/日期。

## A. 材料完整性

- [ ] 参赛身份、机构/团队、联系人、系统版本真实可核验
- [ ] 公开 GitHub 仓库可访问，包含参赛代码与固定 commit
- [ ] README、Docker 启动命令、API 入口、依赖配置、运行步骤齐全
- [ ] 原始方法来源、作者、技术报告与**全部**本次改动已披露（见 `aml/CHANGES.md`、`aml/ATTRIBUTION.md`）
- [ ] Add/Search 接口信息、鉴权、容量、超时、限流、留存说明已提交

## B. 接口契约

- [ ] Smoke 已通过：Add/Search 返回结构与鉴权完全符合现行协议
- [ ] Add 同步返回：数据持久化且立即可检索后才返回 HTTP 200
- [ ] Search 只返回记忆证据，不生成最终答案、不把答案伪装成记忆
- [ ] 响应数量 ≤ top_k，且按相关度排序

## C. 隔离与数据安全

- [ ] 记忆按 `user_id` 严格隔离，不跨用户/任务/样本/团队共享或检索
- [ ] 评测数据及其派生副本仅用于完成当次任务
- [ ] 不用于训练、微调、产品分析、数据集重建或对外传播
- [ ] 任务结束 30 天内删除评测数据（本系统默认 `AML_DATA_TTL_DAYS=30` 自动清理）
- [ ] 不记录/不公开含消息正文的日志

## D. 诚信承诺

- [ ] 未硬编码任何答案或针对评测集的规则
- [ ] 未泄漏、未试图获取私有评测数据/金标准答案
- [ ] 未使用提示词注入、人工实时答题、结果操纵或恶意刷榜
- [ ] 未进行未披露的代码复用；如后续改动上游文件将再次更新披露

## E. 版本冻结确认

- [ ] 正式 Full 受理后：代码、镜像、API、鉴权与申报一致；不因结果不理想更换版本
- [ ] 接口在提交后至 2026-11-04 保持稳定公网可访问，期间不改 API 契约/鉴权/容量
