# 材料 06：本地部署与连通性测试手册（Local Deploy & Connectivity Test）

> 目的：在提交赛事前，先在**本地/测试机**把赛事开发仓库跑通“启动 → Add → Search →
> 契约校验”全链路，确认修改后的项目可完整参赛、可完成评测。

## 1. 一键脚本（推荐）

仓库内已提供两个一键脚本与一个 Python 端到端启动器：

| 文件 | 适用 | 说明 |
| --- | --- | --- |
| `aml/scripts/deploy_local.sh` | Linux / macOS / WSL / GPU 服务器 | 克隆→装依赖→单测→启动→连通性测试 |
| `aml/scripts/deploy_local.ps1` | Windows PowerShell | 同上（Windows 原生） |
| `aml/scripts/run_local_e2e.py` | 任意平台 | 实际执行：启动服务→等待 /health→Add→Search→校验 |

Linux / WSL / GPU 服务器（推荐，依赖 wheel 最全）：

```bash
git clone https://github.com/bubaa9531-dh/Mandol.git Mandol-local
cd Mandol-local
bash aml/scripts/deploy_local.sh
```

Windows PowerShell：

```powershell
git clone https://github.com/bubaa9531-dh/Mandol.git Mandol-local
cd Mandol-local
powershell -ExecutionPolicy Bypass -File aml\scripts\deploy_local.ps1
```

> Windows 提示：若 `uv sync` 因个别依赖（如 rocksdict / faiss-cpu）在 Windows 无
> wheel 而失败，请使用 Docker（Linux 容器）或 Linux/WSL/GPU 服务器执行，命令一致。

## 2. 分步说明（等价于脚本内部逻辑）

1. **获取代码**：克隆赛事开发仓库并切到 `main`；
2. **环境**：Python 3.12（>=3.12,<3.13）、`uv`（脚本会在缺失时用 pip 安装）、git、curl；
3. **安装依赖**：仓库根目录 `uv sync --frozen --no-dev`（首次下载量大：torch 等，
   需联网、磁盘预留 ≥6 GB；不会安装 dev/docs/CUDA/flash-attn 等可选组）；
4. **单元测试**：`uv run pytest tests/ -q`（契约 + 服务链路共 12 项，全部通过）；
5. **配置**：`cp aml.env.example .env`（首次运行默认即可连通；正式评测前再设置
   `AML_MEMORY_SYSTEM_KEY`、按需改 `AML_EMBEDDING_MODEL`）；
6. **端到端连通性测试**：`uv run python aml/scripts/run_local_e2e.py`
   - 自动启动服务（日志 `mandol_aml_e2e.log`）；
   - 轮询 `GET /health` 直到 200（首次会下载默认 embedding 模型 `Qwen/Qwen3-Embedding-0.6B`，
     可能需要数分钟）；
   - 发送一个契约标准 `Add`，校验 `success=true` 与 `request_id/user_id/session_id` 逐字回显；
   - 发送 `Search`，校验返回 `data` 数组、字段齐全、数量 ≤ top_k 且至少 1 条相关记忆；
   - 退出前自动停止服务（或加 `--keep-running` 保留）。

也可单独复用已有服务：

```bash
uv run python -m mandol_aml &        # 另开终端启动
python aml/scripts/smoke_test.py --base-url http://127.0.0.1:8000
```

## 3. 通过判据（满足即视为“本地全链路连通”）

- [ ] `pytest tests/ -q` 全绿（12 passed）；
- [ ] 服务启动日志无致命错误；`GET /health` 返回 200；
- [ ] `run_local_e2e.py`（或 `smoke_test.py`）输出全部 `ok:` 且退出码为 0；
- [ ] Add 返回 HTTP 200 且 `success=true`、三个 ID 逐字回显；
- [ ] Search 返回 HTTP 200 且 `data` 为数组、每条含非空 `id/content`、条数 ≤ top_k；
- [ ] 未配置 Key 时端点开放（仅用于本地 Smoke）；正式评测前设置 Key 后再验一次 401 行为。

## 4. 与“完整参赛 / 完成评测”的对应关系

| 阶段 | 说明 | 何时完成 |
| --- | --- | --- |
| 本地连通性测试（本文档） | 验证修改后代码在本机可启动且 Add/Search 符合契约 | 现在可做 |
| 部署公网 HTTPS + Key | 接口须可被平台访问；URL 不含凭据；设置 Memory System Key | 报名后、评测前 |
| 平台 Smoke | 平台按其 Smoke 流程调用 Add/Search/鉴权，确认兼容 | Smoke 1/小时 |
| Full 正式评测 | 平台跑全量套件并评分；受理后版本冻结 | 周期内至多 2 次 |
| 复核与公榜 | 材料、版本、合规复核通过后进入公榜 | 11 月中旬 |

## 5. 常见问题排查

| 现象 | 处理 |
| --- | --- |
| 模型下载慢/失败 | 设置 HF 镜像：`HF_ENDPOINT=https://hf-mirror.com`（上游 env.template 支持）；或预下载后设 `HF_HOME` |
| 首次 /health 长时间 503 | 属正常：模型下载/加载；查看日志 `mandol_aml_e2e.log` |
| `uv sync` 失败（个别 wheel 无 Windows 版） | 改在 Docker/Linux/WSL/GPU 服务器运行 |
| 内存不足 | 关闭其它程序；必要时用 `AML_EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2`（更小）或 `isolated` 后端换 `shared` |
| 需要 GPU 加速 | Docker/服务器加 CUDA；本 CPU 模式即可完成连通性测试 |
| 密钥 | `AML_MEMORY_SYSTEM_KEY` 与 LLM provider Key 由项目总负责人提供，仅在部署端 `.env` 配置，绝不入仓库 |
